# VibeLaunch — Project Brief

## What is VibeLaunch?

VibeLaunch is a launch platform for founders who build with AI tools and need to ship on X (Twitter) with analytics and SEO from day one.

## Core Value Proposition

1. **Connect X** — OAuth 2.0 sign-in, no manual API key management
2. **Manage Projects** — CRUD for launch projects with slug-based identity
3. **Schedule & Publish** — QStash-backed post queue with media processing
4. **Learn & Adapt** — ERI analytics + pgvector reinforcement for content generation
5. **SEO Changelog** — Auto-expanded changelog pages with Google indexing

## Target User

Solo founders and indie hackers launching AI-built products who want X distribution + SEO without stitching together 5 tools.

## Current Status

All four phases implemented (see `activeContext.md`).
